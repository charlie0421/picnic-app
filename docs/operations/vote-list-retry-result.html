투표 목록 통신 실패 재시도 개선

2026-09-13 · fix/startup-loading-picnic-2665

구현·회귀 테스트·정적 분석·Opus 독립 리뷰 완료. 차단 지적 없음.

반영한 동작

  • 첫 조회 실패는 오류 안내와 재시도 버튼을 표시합니다. 정상적으로 조회한 결과가 비어 있을 때만 ‘투표 없음’을 표시합니다.
  • 추가 페이지 조회 실패는 기존 카드와 스크롤 위치를 유지하고 하단에 재시도를 표시합니다. 재시도는 실패한 페이지부터 요청합니다.
  • 필터 뒤 빈 페이지를 확인하다가 통신에 실패해도 목록 끝으로 판정하지 않습니다.
  • 재시도 연타는 하나의 요청으로 처리하고, 이전 필터·새로고침 세대의 늦은 응답을 버립니다. 오류 캐시와 이전 세대의 후속 페이지도 무효화합니다.
  • 서버 예외 원문은 화면에 표시하지 않습니다. 기존 provider 자동 재시도 정책은 유지하며, 오류가 확정되면 사용자가 다시 요청할 수 있습니다.

검증

목록·탭·provider·이미지 선로딩 회귀 테스트 173개 통과(신규 재시도 테스트 7개 포함). 변경 파일 2개 정적 분석 지적 없음. 첫 오류·추가 페이지 오류는 실제 VoteList 위젯에서 확인했습니다.

이번 변경은 위젯 테스트로 장애를 주입해 검증했습니다. iOS/Android 앱 빌드·실기기 검증을 새로 수행한 결과는 아닙니다. 버전·태그·배포 상태도 변경하지 않았습니다.

리뷰 처분

Opus가 재시도·캐시 무효화·세대 변경·PIC 후속 페이지 실패 처리를 승인했습니다. 테스트 포맷 지적은 반영했습니다. 데이터 반영 뒤 선로딩 스케줄 계산 자체가 예외를 내는 경우의 추가 방어와 디자인 토큰 통일은 현재 재현된 차단 문제 없이 후속 권고로 남았습니다.
