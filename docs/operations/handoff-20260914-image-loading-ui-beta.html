4. 내부 베타에서 우선 확인할 항목

  1. Codemagic iOS 빌드 완료, App Store Connect 업로드, Shorebird release 생성 여부를 확인한다.
  2. Android 워크플로가 태그로 시작됐는지 확인한다. 시작되지 않았다면 태그를 이동하거나 삭제하지 말고 원인을 조사한다.
  3. TestFlight와 Google Play 내부 테스트에서 콜드 스타트·스플래시 체류 시간과 홈 첫 이미지 표시 시간을 관찰한다.
  4. 투표 목록을 빠르게 스크롤하고 진행중↔예정됨 필터를 반복해 이미지 재사용과 카드 하단을 확인한다.
  5. 로그인 계정으로 일반·JMA 투표 팝업의 이미지, 숫자 키보드, 스크롤, 충전 버튼을 확인하되 실제 투표·결제는 테스트 계정에서만 수행한다.
  6. 스토어 구매 상품 목록이 실제 내부 배포 환경에서 로딩을 끝내는지 확인한다.
남은 관찰점: Android QA 앱의 구매 상품 목록은 실기기 검사 당시 로딩 상태에 머물렀다. 무료 충전소는 정상 표시됐고 구매 UI는 위젯·골든 테스트를 통과했지만, 실제 스토어 상품 조회는 내부 베타에서 다시 확인해야 한다.

5. 작업 제한 및 주의

  • 실제 투표, 결제, 문의 전송, 북마크, 알림 모두 읽음 처리는 QA 중 실행하지 않았다.
