범위 및 제한

  • 방송 알림 읽음은 같은 기기·같은 계정에 저장됩니다. 기기 간 동기화는 포함하지 않습니다.
  • 후속 구현은 기존 Dart 코드와 저장소 계약을 사용하며 원격 DB 스키마 변경을 포함하지 않습니다.
  • 통신 실패·새로고침 경합·본문 보존·알림 읽음 경계 조건은 자동 테스트로 검증했습니다. 실제 문의 제출, 모두 읽음 실행, 원격 푸시 발송을 통한 종단 검증은 수행하지 않았습니다.
  • iOS 기기 조작으로 문의 입력창에 직접 본문을 입력하는 검증은 완료하지 못했습니다. 카테고리 전환 후 본문·선택·첨부 보존은 실제 위젯을 사용하는 회귀 테스트로 확인했습니다.
  • 푸시 서비스의 실제 퍼사드와 초기화 조정자·APNS 대기·소유권을 테스트했습니다. Firebase/권한/Supabase 경계의 일부 플랫폼 연결 코드는 독립 코드 리뷰로 확인했습니다.
  • APNS 조회에서 예외가 발생하면 현재 대기는 종료되며 다음 앱 복귀 시 재시도합니다.
