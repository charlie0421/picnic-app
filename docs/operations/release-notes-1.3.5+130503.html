스토어 "새로운 기능" 문구

표시 버전 1.3.5 전체(1.3.4 대비)를 기준으로 썼다. 스토어 문구는 표시 버전 단위로 노출되기 때문이다.

한국어

• 투표 완료 화면이 작은 화면과 큰 글자 설정에서도 잘리지 않도록 개선했어요.
• 여러 언어에서 버튼과 안내 문구가 잘리거나 넘치던 부분을 바로잡았어요.
• 저장 버튼과 투표 후보 신청 화면의 어색한 번역을 고쳤어요.
• 투표 상세 화면과 리워드 이미지가 더 빠르게 열려요.
• 결제가 중간에 끊겼을 때 구매 내역을 복구하는 과정을 더 안정적으로 만들었어요.
• 캔디부스트 이벤트 기간이 이번 주 날짜로 정확하게 표시돼요.
• 베트남어·인도네시아어 번역을 전체적으로 다듬었어요.

English

• The vote-complete screen no longer gets cut off on small screens or with large text.
• Fixed buttons and labels that were clipped or overflowing in several languages.
• Corrected awkward translations on the Save button and the candidate request screens.
• Vote details and reward images now load faster.
• Made recovery of interrupted purchases more reliable.
• Candy Boost event dates now show the current week accurately.
• Revised Vietnamese and Indonesian translations throughout the app.

QA 확인 포인트

  • 캔디부스트 기간 (#263·#264) — 결제 화면 뱃지의 기간이 이번 주 회차 날짜(월~수)로 보이는지, 회차가 끝난 뒤 앱을 다시 열면 갱신되는지 본다. 홈 배너는 꺼져 있어야 한다.
  • 글자 크기 상한 (#261) — iOS 손쉬운 사용 글자 크기를 최대로 올려도 앱이 2.6배 이상 커지지 않고, 달성 투표 상세 머리가 화면 안에 있는지 본다.
  • vi·id 번역 (#260·#262) — 마이페이지(회원탈퇴·충전·공지), 투표 후보 신청 상태, 이용 정지 안내를 두 언어로 본다.
  • iOS 미완료 결제 복구 (#255) — PR 에 "실기기 결제 복구·운영 지급 확인은 남아 있음" 으로 적혀 있다. 결제 도중 앱을 종료한 뒤 재실행해 재화가 지급되고 거래가 한 번만 완료되는지 본다.
  • 투표 버튼 (#251) — 한국어·영어는 기존 디자인과 같아야 한다. es·vi·bn_BD 등 긴 라벨은 한 줄로 줄어들고 말줄임이 없어야 하며, 키보드를 열어도 버튼 폭이 같아야 한다.
  • 저장·공유 버튼 (#247~#249) — 여섯 화면 중 완료 팝업과 투표 상세에서 es·bn_BD·my 라벨이 버튼 안에 있는지 본다.
  • 큰 글자 설정 (#252·#253·#256) — 시스템 글자 크기를 최대로 하고 로그인 버튼, 닉네임 입력, 가입 약관 제목, 카운트다운을 본다.
  • 투표 상세 (#254) — 후보 목록·순위·득표수가 이전과 같고, 삭제된 후보가 보이지 않는지 본다.
  • 완료 팝업 (#241·#244) — 작은 기기에서 팝업이 잘리지 않고, 저장한 공유 이미지가 화면과 같은지 본다.

알려진 제한

  • 버마어 저장·공유 라벨은 임시로 영어다. 맞는 표기가 확인되면 #249 를 되돌린다 (PICNIC-2729).
  • #248 의 es·vi·fil·bn_BD 번역은 원어민 확인 전이다. 되돌려도 레이아웃은 #247 이 보장한다.
  • 이 태그는 -skip-tests 라 Codemagic 에서 picnic_lib 의 긴 커버리지 테스트 단계를 건너뛴다. 릴리스 가드 테스트는 실행된다.
