3. 원 보고서 정정 · 철회 (root 지적 검증 결과)

항목검증 결과
H1 "정확히 31초" 정정 root 지적대로 abort 경로가 섞이면 31초는 성립하지 않는다. att-status가 타임아웃하면 catch가 조기 반환해 1초 프레젠테이션 지연이 실행되지 않기 때문이다. 다만 31초 자체는 도달 가능하다 — 각 단계가 바운드 직전에 성공하는 경로 (att-status ≈5s 성공/notDetermined → 지연 1s → 프롬프트(제외) → 거부 → config ≈5s → UMP 4×5s)에서 기계 시간 합계가 ≈31초가 된다. 표기를 "최대 ~31초(단계별 근접-성공 누적 시)"로 정정한다. 결론(총량 예산 필요)은 유지되며 이미 해소됐다.
H4 "신규 결함" 분류 오류 — 정정 root 지적이 옳다. HEAD에서도 한 콜드 스타트에 UMP 경로가 둘이었다: git show HEAD:main_initializer.dart:96 (group1.add(AppInitializer.initializePrivacyConsent()) → privacy_consent_manager.dart:50 _initializeUMP → ConsentInformation.instance.requestConsentInfoUpdate 직접 호출) 와 :129 _initializeAdMob() → :233 await ConsentService().initialize(). 게다가 HEAD의 ConsentService.initialize()에는 single-flight 자체가 없었다. 따라서 이번 작업은 중복을 만든 것이 아니라 줄였고, 교정 가드가 남은 자동 반복까지 닫았다. "신규" 라벨을 철회하고 "기존 문제, 이번 작업으로 축소 → 교정으로 종결"로 정정한다.
H5 디버그 지오그래피 복원 권고 철회 root 지적이 옳다. HEAD의 testIdentifiers: ['TEST-DEVICE-HASHED-ID'](privacy_consent_manager.dart:58)는 Google 문서의 리터럴 플레이스홀더다. UMP의 debugGeography는 등록된 테스트 디바이스에만 적용되므로 실제 기기가 매칭될 수 없고, 즉 HEAD 시점에도 이미 동작하지 않던 코드다. "프로덕션 수정으로 플레이스홀더를 되살리지 말라"는 지적을 수용해 권고를 철회한다. 새 디버그 지오그래피 정책 요구도 없으므로 조치 없음.
H6 Android ATT 우회 수용 — 정보성으로 강등 iOS 전용 API에 대한 의도된 정정으로 확인. PrivacyConsentManager.canShowPersonalizedAds는 세 lib 트리(picnic_lib/lib, picnic_app/lib, ttja_app/lib) 전체에서 프로덕션 호출부 0건(정의부만 존재). 실제 영향 없음.
H7 설정 버튼 재현 시나리오 재현 경로 철회 root 지적이 옳다. showPrivacyOptionsForm은 세 lib 트리 전체 grep 결과 consent_service.dart:433 정의부 외 호출부가 0건이다. "설정 화면에서 개인정보 옵션을 누르면"이라는 재현 시나리오는 현재 앱에 존재하지 않는 경로이므로 철회한다. _isFlowCurrent(null, …)의 _activeAttempt 미관찰은 dead code 상의 잠재 흠으로만 남긴다.

  1. 남은 차단 요소 없음 — 리뷰 종결. H1–H4 해소, N1-a 수정 확인, N1-b 철회, N2 해소.
  2. 후속 1순위 — N1 → 종결. 고정 프레젠테이션 지연은 예산 밖으로 이동됐고, 상태 채널 무응답 시의 fail-closed는 의도된 계약임을 확인해 지적을 철회했다 (동일 MethodChannel이므로 fallback은 splash hang을 재도입한다).
  3. 후속 2순위 — N2 → 종결. on AdsUnavailable 전용 절로 Sentry 진입과 "광고 소진" 오안내가 모두 제거됐고, 다른 SDK 예외 처리는 보존된다.
  4. H5는 조치 없음(철회), H6·H7은 정보성으로만 유지.
  5. §5의 잔여 테스트 공백은 이번 범위 밖 후속 항목으로 유지한다(신규 지적 추가 없음).
