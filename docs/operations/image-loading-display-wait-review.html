패키지 문서가 Duration.zero를 "This is useful for automated tests."(visibility_detector-0.4.0+2/lib/src/visibility_detector_controller.dart, updateInterval doc)로 규정한 모드를 프로덕션이 상시 채택하는 형태다. 이 모드에서 RenderVisibilityDetectorBase._processCallbacks는 초당 최대 2회가 아니라 매 프레임 post-frame 콜백으로 실행되고, 보이는 detector마다 _determineVisibility(render_visibility_detector.dart:167-224)가 돈다 — 조상 RenderObject 체인을 루트까지 paintsChild로 순회 + 조상 Layer List<ContainerLayer>와 임시 ContainerLayer() 할당 + 레이어별 describeClipBounds/transformRect/Rect.intersect/applyTransform. 예정 투표 카드는 한 화면에 썸네일 12개(테스트가 maximumActiveRequests == 12로 고정)이므로 스크롤 중 프레임당 12회다. 개략 추정으로는 프레임당 수백 µs 수준이라 자체로 잰크를 만들 가능성은 낮다.
