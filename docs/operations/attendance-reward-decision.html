출석 보상 폐지 — 1b 차단 해제 검증

작성 2026-07-31 (v2 — 오너 확인 "출석 보상 폐지" 반영, A/B/C 옵션 비교였던 v1 을 대체) · 검증 기준 앱 picnic-app@d6ff164d7(=1.3.0 제출 기준 커밋), 엔진 picnic-supabase-cotton-candy-engine

결론 — 출석 보상 폐지는 1.3.0 코드에 이미 실질 반영돼 있다(보상 RPC 를 부를 수 있는 UI 진입점이 전부 끊김). 따라서 핸드오프 §5-4 "출석 재화 단위 60/120↔1/7 제품 결정" 항목은 해소되고, 1b 는 출석 때문에 막히지 않는다. 서버 마이그레이션·엣지 함수 수정·앱 릴리스 모두 불필요. 남는 것은 잔여 리스크 2건(§3)과 정리 부채(§4)뿐이다.

1. 무엇이 문제였나 (요약)

엣지 함수 attendance-check 는 출석 체크 시 60(일일)/120(주간)을 DB 함수 process_attendance_check 에 전달한다. 1b 가 교체하는 wallet 본문은 1/7 만 정답으로 하드코딩하고 불일치 시 WALLET_ATTENDANCE_REWARD_MISMATCH 로 raise 한다(prod-cutover/1b/06:28-29,54-56). 즉 출석 기능이 살아 있다면 1b 적용 순간 출석이 전량 실패하는 구조였고, 이것이 MANIFEST 오픈리스크 #2 였다.

2. 폐지가 코드에 반영됐다는 근거 (1.3.0 = origin/main 검증)

#확인 내용근거
1보상 RPC 를 부르는 것은 checkIn() 뿐이고, attendanceProvider.build() 는 상태 조회만 한다 (보상 RPC 미경유)picnic_lib/lib/presentation/providers/attendance_provider.dart:20,27,93
2checkIn() 호출자는 출석 다이얼로그/탭 UI 뿐인데, 그 진입점 AttendanceIconButton 은 어디서도 참조되지 않는 고아 위젯이다 (헤더에서 제거됨: 커밋 f89dae324 "remove … attendance from top bar", 이동 이력 8b1a81819)attendance_icon_button.dart 참조 검색 0건
3무료 충전소의 출석 탭도 제거됨 — free_charge_station.dart 에 attendance_check_tab 은 미사용 import 만 남아 있음free_charge_station.dart:38 (본문 사용 0건)
4app_initializer.dart 의 ref.invalidate(attendanceProvider) 2곳은 리스너가 없으면 재빌드를 일으키지 않고, 리스너가 될 위젯이 전부 고아라 런타임에 provider 자체가 빌드되지 않는다app_initializer.dart:779,813

정리하면: 1.3.0 사용자는 출석 화면에 도달할 수 없고, 도달 불가이므로 checkIn() → 60/120 전달 → 1b 본문 raise 경로는 실행될 수 없다.

3. 잔여 리스크 2건 (수용 가능, 인지만)

  1. 강업을 뚫는 구버전 코호트. 강업(ForceUpdateOverlay)은 checkUpdate 가 깨진 일부 구 릴리스 코호트에 노출되지 않는다(기존 확인 사항). 이 사용자들의 구버전 앱에는 출석 UI 가 살아 있으므로, 1b 이후 출석 체크 시 에러를 보게 된다. 폐지가 제품 결정이므로 조용한 성공보다 명시적 실패가 오히려 정합 — 다만 CS 문의 가능성이 있으니 응대 한 줄("출석 보상은 종료되었습니다. 최신 버전으로 업데이트해 주세요")을 CS 런북에 추가해 두면 된다.
  2. 1b 본문의 raise 는 트립와이어로 남는다. 폐지 후 누군가 출석 경로를 되살리면(코드 복원·수동 호출) 60/120 전달 시 즉시 실패한다. 이는 결함이 아니라 의도치 않은 부활을 막는 안전장치로 작동하므로 그대로 둔다. SQL 커버리지 테스트의 1/7 계약 고정도 이제 본문과 정합이라 수정 불필요.

4. 후속 정리 부채 (급하지 않음, 1b 와 무관)

  • 앱 데드코드 제거 (chore PR 1건 감): AttendanceIconButton · attendance_dialog.dart · attendance_check_tab.dart 외 attendance 위젯 일체(하드코딩 +60/+120 포함), free_charge_station.dart:38 미사용 import, app_initializer.dart 의 invalidate 2곳, attendance 위젯 테스트. attendanceProvider 와 관련 l10n 키(label_attendance_weekly_bonus 등)도 함께.
  • 엣지 함수 attendance-check 회수: 강업 완료 후(구세대 트래픽 소멸 후) 배포 목록에서 제거하거나 410 응답으로 교체. 롤아웃 매니페스트에서도 제외.
  • 문서 정리: MANIFEST 오픈리스크 #2 를 "출석 보상 폐지로 해소(2026-07-31)"로 닫고, 핸드오프 §5-4 항목 제거. attendance_check 테이블·레지스트리(1b 의 migrated 마킹)는 손댈 필요 없음 — 테이블은 0행 그대로 유지된다.
