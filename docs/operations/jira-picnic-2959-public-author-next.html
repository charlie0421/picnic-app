PICNIC-2959 공개 작성자 조회 수정

2026-10-21 KST · 기준 main 078dda32a · 브랜치 fix/picnic-2959-public-author

앱 수정·관련 테스트 127개·별도 Codex 리뷰를 완료했다. 운영 RLS·RPC 적용과 앱 릴리스는 남아 있으므로 Jira 상태를 유지한다.

변경

picnic_lib/lib/presentation/providers/community/post_provider.dart의 postsByUser가 작성자를 user_profiles_public의 공개 6열에서 조회하도록 바꿨다. user_profiles 별칭을 유지하므로 응답 모델은 그대로다. 사용자 범위, 게시판·신고·스크랩 join, 차단·삭제·신고 필터, 정렬과 페이지 조건을 보존했다.

작성자가 null이면 기존 공유 helper가 TypeError를 냈다. 다른 게시글 목록과 같은 PostModel.fromJson 파서를 사용해 작성자가 없는 게시물도 유지한다. nullable 게시판 매핑도 기존 모델 파서가 담당한다. 공유 helper나 다른 조회 경로는 변경하지 않았다.

리뷰

별도 Codex/high 읽기 전용 리뷰에서 blocking findings가 없었다. 공개 6열·alias, 기존 필터·join·정렬·페이지, nullable 작성자·게시판 매핑을 대조했고 worker_done succeeded를 확인했다. 실제 PostgREST FK 관계 해석·운영 schema cache·RLS 동작과 배포는 이번 mock 테스트 및 코드 리뷰로 검증하지 않았다.

사용자는 이번 고위험 작업의 별도 Codex 세션 리뷰를 승인했다. 구현과 리뷰는 각각 gpt-6.1-sol/high, Fast OFF, approval never로 실행했다. 구현만 workspace-write이고 리뷰는 read-only다. 네이티브 하위 에이전트는 사용하지 않았다. Run run_bd444d2f1c5b, 구현 Task task_0d2988bb149e·Dispatch ctx_ebb964ccd964, 리뷰 Task task_c5eba67398b8·Dispatch ctx_4b32bcc50589.

남은 작업

  • 앱 PR #288과 이번 수정이 실제 릴리스에 포함돼야 한다. 현재 워크트리 변경은 앱 배포가 아니다.
  • postsScrapedByUser의 본인 프로필 embed는 별도 경로다. 공유 helper의 null 비안전 구현은 남아 있지만 postsByUser는 더 이상 호출하지 않는다.
  • 서버의 get_user_profile fail-closed 킷과 RLS 킷은 별도 운영 승인·적용·사후 검증이 필요하다. user_profiles RLS는 10월 21일 재조회에서도 OFF다.
  • receipts·star_candy_history 등 이슈의 나머지 노출 범위는 별도로 남는다. 이번 앱 수정으로 PICNIC-2959 전체를 완료 처리하지 않는다.

의존성은 flutter pub get --offline으로 준비했다. 추적된 의존성 파일 변경은 없다. .env·비밀키를 읽거나 복사하지 않았으며 앱 버전·운영 DB·배포 설정을 바꾸지 않았다.
