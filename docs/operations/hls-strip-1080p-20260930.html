자체숏폼 광고 HLS 마스터에서 1080p 변형 제거 (720p 상한)

적용 2026-09-30 · QnA 395 후속 과제 2번 · 조사 문서 docs/operations/qna-395-global-pick2-load-fail.html · 스크립트 scripts/hls_strip_1080p.sh

1. 무엇을 왜 바꿨나

  • 자체숏폼(글로벌픽#2) 광고 영상은 19초짜리인데 마스터 플레이리스트가 1080p(5.1 Mbps)부터 시작했다. 1080p 첫 세그먼트는 2.66 MB 라 1 Mbps 이하 이동통신망에서는 앱의 초기화 타임아웃(당시 15초, PR #278 이후 30초) 안에 못 들어와 "광고 로드에 실패했습니다"가 났다.
  • 앱은 서버가 준 URL 을 항상 <id>/master.m3u8 로 치환하므로(shortform_internal_platform.dart 의 rewriteVideoUrlIfNeeded), 설치된 앱에 바로 효과가 있는 지렛대는 master.m3u8 의 내용뿐이다.
  • 그래서 S3 의 master.m3u8 10개에서 1080p #EXT-X-STREAM-INF 줄과 그 URI 줄만 뺐다. 720p·480p·360p·240p 변형과 세그먼트는 그대로다. 720p 첫 세그먼트는 약 1.6 MB 라 1 Mbps 에서도 13초면 들어온다.

2. 적용 내역

항목값
버킷 / 프리픽스picnic-prod-cdn / picnic/videos/output/<id>/ (CloudFront d2jrkjksiktw4e.cloudfront.net)
대상출력 11개 중 master 가 있는 10개 (캠페인 9개: 활성 8·일시정지 1 전부 포함). 73125b93… 은 master 가 없어 건너뜀
백업각 폴더에 master.orig.m3u8 (5개 변형 원본). 스크립트는 백업이 이미 있으면 덮어쓰지 않는다
객체 메타Content-Type application/x-mpegURL, Cache-Control public, max-age=60 원본과 동일
자격증명AWS 프로필 picnic(cdn-user, 어드민 업로드와 같은 키). MediaConvert·Lambda 는 접근 거부
검증S3 재조회 10/10 변형 4개·1080p 0. CloudFront 로 활성 8개 재조회: 전부 변형 4개, 최상위 RESOLUTION=1280x720, 720p 플레이리스트 200, x-cache Hit
멱등 확인재실행 드라이런 changed=0 skipped=11 failed=0

3. 되돌리기

scripts/hls_strip_1080p.sh --restore            # 10개 전부 master.orig.m3u8 로 복원
scripts/hls_strip_1080p.sh --restore --only 5fa8d080-6e1e-48ba-9e63-d3555a03c194

CloudFront 캐시가 60초라 복원도 1분 안에 반영된다. 재생 중인 사용자는 master 를 시작할 때 한 번만 읽으므로 영향이 없다.

4. 새 광고 영상이 올라올 때

트랜스코더는 여전히 1080p 를 만든다. 어드민에서 새 영상을 올려 캠페인을 만든 뒤 아래를 한 번 돌리면 된다. 이미 처리된 master 는 건너뛰므로 전체를 대상으로 돌려도 안전하다.
AWS_PROFILE=picnic scripts/hls_strip_1080p.sh --dry-run   # 먼저 확인
AWS_PROFILE=picnic scripts/hls_strip_1080p.sh

5. 항구 수정 (권한 필요, 미완)

어드민은 picnic/videos/input/<uuid>.mp4 에 올리고(app/ads/components/AdsForm.tsx), AWS 쪽 트랜스코더가 picnic/videos/output/<uuid>/ 에 HLS 를 만든다. 이 트랜스코더의 출력 설정에서 1080p 를 빼면 스크립트가 필요 없어진다. 확인할 곳:

  1. S3 콘솔 → picnic-prod-cdn → 속성 → 이벤트 알림. picnic/videos/input/ ObjectCreated 에 걸린 대상(Lambda 또는 EventBridge)을 찾는다.
  2. 대상이 MediaConvert 잡을 만들면 잡 템플릿의 HLS 출력 그룹에서 1920x1080 출력을 제거한다. Lambda 가 직접 설정을 넣으면 그 코드의 출력 목록에서 뺀다.
  3. 바꾼 뒤 테스트 영상을 하나 올려 새 master 에 1080p 줄이 없는지 확인하고, 이 문서와 스크립트 헤더에 "트랜스코더 수정 완료"를 기록한다.

현재 보유한 두 AWS 자격증명(cdn-user, n8n-ec2-user)은 MediaConvert·Lambda 조회 권한이 없어 이 단계는 콘솔 접근 권한이 있는 사람이 해야 한다.

6. 효과 확인 방법

적용 전 7일 자체숏폼 완료율은 93.7~96.7% 였고, Android 10·11 코호트는 69~86% 였다. 며칠 뒤 아래로 전후를 비교한다. PR #278 이 배포되면 Sentry 의 ad_reason=timeout 비율도 같이 본다.

select (issued_at at time zone 'Asia/Seoul')::date as kst_day,
       count(*) issued, count(completed_at) completed,
       round(100.0*count(completed_at)/count(*),1) pct
from public.ad_impressions
where issued_at >= '2026-09-23'
group by 1 order by 1;
