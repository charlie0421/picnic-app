스크린샷 근거

실제 이슈와 측정 한계

  • 이번 보완 후 실행에서 새 이미지 결함·예외·크래시는 확인되지 않았다. 목표였던 rank-3 빈 원형도 현재 표본에서는 재현되지 않았다.
  • 동일 시점의 A/B 실행, 네트워크 shaping, CDN 응답·decode trace를 수행하지 않았다. 따라서 절대 latency와 개선률은 알 수 없다.
  • 4 fps 시각 표본의 시간 해상도는 250 ms다. 이보다 짧은 placeholder가 있었다면 검출하지 못했을 수 있다.
  • sidecar 초기화는 앱 sandbox를 새로 만들지만 OS 이미지 캐시·네트워크/CDN 캐시까지 통제하지 않는다. “cold disk cache” 또는 “cold network”로 부르지 않는다.
  • QA sidecar는 원본 Play 앱과 applicationId·sandbox·서명이 다르다. 기존 Play 앱은 Play App Signing과 로컬 debug 서명이 달라 adb install -r로 교체할 수 없으며, 안전을 위해 uninstall하지 않았다.
  • 기존에 관찰한 홈 재방문 전체-card skeleton은 provider/navigation 상태도 개입할 수 있고 이번 rank-3 변경 범위 밖이므로, 이 보고서에서 해결됐다고 주장하지 않는다.

안전성

  • ADB 입력과 UIAutomator/screencap/screenrecord만 사용했다. 원본 앱 데이터 삭제, uninstall, 계정 로그인, 결제, 실제 투표 제출, 배포, commit/push는 하지 않았다.
  • 알림 권한 프롬프트는 QA sidecar에서 “허용 안함”으로 닫았다. 개인 토큰·세션·SSID·IP는 로그 발췌나 보고서에 포함하지 않았다.
  • PNG·video·verbose log·임시 Android wrapper는 /tmp 중간 자료이며 별도 전달 산출물이 아니다.
