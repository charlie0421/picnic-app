5. 4번 — 아시아픽 #1 “광고 소진”

사용자가 본 문구는 다음 리소스다.

"dialog_title_ads_exhausted":   "모든 광고 소진"

결론. Pangle의 모든 로드 예외 — 진짜 no-fill뿐 아니라 SDK 초기화 실패, 네트워크 오류, 지역/eCPM 필터, 계정·플레이스먼트 설정 문제까지 — 가 사용자에게는 똑같이 “모든 광고가 소진되었습니다”로 보이고, 동시에 Sentry 보고가 차단된다.

따라서 “아시아픽 #1이 소진 상태”라는 CS 진술은 액면 그대로 신뢰할 수 없다. 그리고 원인을 가릴 텔레메트리도 현재 남지 않는다.

프로덕션 Pangle 광고 ID는 picnic_app/config/prod.json의 ads.pangle에 4개 항목(ios_app_id, android_app_id, ios_rewarded_video_id, android_rewarded_video_id) 모두 설정되어 있으므로, 최소한 ID 미설정 경로는 아니다.

참고 — 자체 캠페인의 재고 소모 시점 (글로벌 픽 #1 해당)
