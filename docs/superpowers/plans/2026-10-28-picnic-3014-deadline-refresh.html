PICNIC-3014 마감 재조회 분산

2026-10-28 사용자가 승인한 설계: 마감 표시는 즉시 바꾸고, 상세·후보 재조회는 클라이언트별 1~5초 뒤에 실행한다. 구현 범위는 일반 투표 상세 화면이다. 서버의 투표 마감·지갑 잠금은 변경하지 않는다.

완료 조건

  • 로컬 마감 시각에 종료 UI를 반영한다.
  • 마감 상세·후보 재조회는 1~5초 분산하고 한 번 실행한다. 대기 중 자동 폴링과 스크롤 종료 재조회를 억제한다.
  • 예정 투표의 시작 전환과 사용자 새로고침은 지연하지 않는다.
  • 페이지 종료·대상 변경 시 예약을 취소한다. 실패 후 자동 폴링을 복구한다.
  • 마감 경계, 중복 콜백, 수동 새로고침, 페이지 종료, 오류, 기존 폴링·탭 동작을 테스트한다.
  • 다른 공급자의 읽기 전용 리뷰와 필요한 수정 후 커밋한다. 배포와 Jira 상태 전환은 포함하지 않는다.

실행 순서

  1. 고정 시계·지연을 주입하는 테스트 경로를 준비하고 요청 기록으로 현재의 즉시 재조회 문제를 재현한다.
  2. 상세 페이지에 마감 상태 갱신, 단일 예약 및 취소를 추가한다. 공유 타이머는 안전한 콜백과 경계 재시작만 보완한다.
  3. 관련 위젯 테스트와 정적 분석을 실행한다.
  4. 사용량·모델 지원·권한을 확인한 Orca 리뷰어가 diff와 테스트 결과를 검토한다.
