기존 네이티브 시작 화면 복원 구현 계획

에이전트 작업 규칙: 이 계획은 superpowers:executing-plans 절차로 순서대로 실행한다. 설정과 생성 바이너리는 단위 테스트 대신 기준 브랜치와의 바이트 단위 비교로 RED/GREEN을 검증한다.

목표: Android·iOS의 첫 번째 네이티브 시작 화면을 main의 기존 아이콘과 배경으로 복원하면서 두 번째 Flutter 스플래시와 반응형 레이아웃을 유지한다.

구조: 네이티브 설정 1개와 생성 리소스 13개를 main에서 그대로 복원한다. flutter_native_splash 생성기는 실행하지 않으며, Flutter 위젯·테스트·이미지 에셋은 수정하지 않는다.

기술: Flutter, Android XML/PNG 리소스, iOS Asset Catalog, Git 바이트 비교, Xcode profile 빌드

전역 제약

  • 첫 번째 네이티브 화면은 Android와 iOS 모두 main과 동일해야 한다.
  • picnic_app/assets/splash_key.png와 ResponsiveSplash는 변경하지 않는다.
  • flutter_native_splash 생성기를 다시 실행하지 않는다.
  • 복원 대상은 아래 명시된 14개 경로로 제한한다.
  • 실장비 확인은 디버그 직접 실행이 아닌 profile 빌드로 수행한다.

파일 구조

  • 복원: picnic_app/flutter_native_splash.yaml — 기존 네이티브 스플래시 생성 설정
  • 복원: Android의 밀도별 splash.png 5개, 배경 PNG 2개, Android 12 스타일 XML 2개
  • 복원: iOS의 LaunchBackground PNG 1개와 LaunchImage PNG 3개

작업 2: 원격 브랜치와 PR

  1. 브랜치 푸시

    git push -u origin fix/splash-size

  2. PR 본문 준비

    ## Summary
- Preserve the original Android and iOS native launch screen.
- Restore the Flutter splash scale on conventional phones while bounding Fold and tablet layouts.
- Remove the global portrait-only orientation lock.

## Verification
- `flutter test` (41 tests)
- `flutter analyze` in `picnic_app`
- `flutter analyze lib/core/utils/system_ui_initializer.dart` in `picnic_lib`
- iPhone 12 mini profile build, install, launch, and visual check

    위 내용을 플랫폼이 요구하는 Markdown 형식으로 /private/tmp/picnic-splash-pr-body.md에 저장한다.

  3. main 대상 PR 생성

    gh pr create \
  --base main \
  --head fix/splash-size \
  --title "fix(splash): preserve native launch on responsive screens" \
  --body-file /private/tmp/picnic-splash-pr-body.md

    PR 본문에는 네이티브 시작 화면 보존, Flutter 반응형 크기, 방향 잠금 제거, 테스트·분석기·profile 실장비 결과를 기록한다.

  4. Vercel Preview URL 확인

    PR=$(gh pr view --json number --jq .number)
for i in $(seq 1 8); do
  URL=$(gh api "repos/:owner/:repo/issues/$PR/comments" \
    --jq '.[] | select(.user.login=="vercel[bot]") | .body' 2>/dev/null \
    | grep -oE 'https://[a-z0-9-]+\.vercel\.app' | head -1)
  [ -n "$URL" ] && echo "Preview: $URL" && break
  sleep 20
done

    최대 8회 안에 URL이 없거나 명령이 실패하면 재시도하지 않고 조용히 종료한다.
