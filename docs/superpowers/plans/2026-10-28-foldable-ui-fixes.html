폴더블 UI 개선·검증 결과

2026-10-28 · 기준 d2e8b72a6 · 브랜치 docs/foldable-ui-audit

공통 UI 개선을 적용했다. 화면 크기·키보드 정보 갱신, 짧은 투표 화면의 스크롤, 접기 전환 중 현재 투표 보존을 수정했다. 관련 자동 테스트 287개가 통과했다. Android 에뮬레이터와 iPad 시뮬레이터에서 실제 키보드도 확인했다.

iPhone Duo 지원은 완료되지 않았다. UIScene 전환 후보는 Duo 시작 충돌을 해소했지만, 콜드 스타트 링크·알림 회귀 위험과 키보드 실패가 남았다. 후보를 최종 실행 코드에서 제외하고 이 문서에 보존했다. 최종 브랜치에는 기존 iOS 시작 경로가 남아 있다. Galaxy Fold8의 실제 One UI 기기를 인증한 결과도 아니다.

요청과 적용 범위

사용자의 “개선 진행” 요청에 따라 기존 감사의 우선 개선 항목을 구현·검증했다. 기존 600 논리 픽셀 너비 상한과 글자 배율 상한 2.6을 유지했다. 두 열 재설계, 앱 전체 ScreenUtil 교체, 버전·배포·인증·결제 로직·의존성 변경은 수행하지 않았다. 실결제·실투표·실로그인은 실행하지 않았다.

실패를 먼저 확인한 회귀

  • 현재 화면·키보드 정보 테스트가 수정 전 실패하고 FixedWidthLayout 변경 후 통과했다.
  • 390×844→600×400 전환에서 현재 투표가 페이지 1에서 0으로 돌아갔다. 항상 같은 트리를 유지하도록 바꾼 후 동일 카드 Element와 페이지가 유지됐다.
  • 600×400, 배율 2.6에서 저장·공유 버튼 하단이 창 아래에 남았다. 카드 끝의 드래그를 바깥 스크롤에 전달한 후 버튼 전체 노출과 hit test가 통과했다. 같은 드래그는 다음 투표로 넘어가지 않는다.
  • 달성형에 보상 5개가 실제로 렌더링된 뒤 버튼 터치가 실패했다. 달성형도 공통 카드 스크롤을 사용하도록 수정한 뒤 통과했다. 빈 달성형 상태의 통과만으로 판정하지 않았다.
  • 바깥 창을 스크롤한 뒤 다음 투표로 이동하면 제목 상단이 170.0, 창 상단이 250.56으로 약 80.56px 잘렸다. 페이지 변경 후 바깥 위치를 초기화한 뒤 통과했다.

시뮬레이터·에뮬레이터 실행 근거

실제 Runner의 진단용 integration_test/device/foldable_layout_device_test.dart에서 생산 코드 FixedWidthLayout과 입력 필드를 실행했다. 로그인 후 전체 앱 탐색을 대신하지 않는다. 투표 다이얼로그 테스트의 서비스 응답은 테스트 대역이다.

독립 리뷰와 남은 범위

Codex가 구현하고 Claude Opus 5.5 / high가 읽기 전용으로 리뷰·재검토했다. Orca Run·Task·Dispatch와 작업자 자체 worker_done으로 완료를 확인했다. 실제 CLI 모델·effort, policyRevision 2 로딩 및 제한된 도구를 확인했다. 라우트의 다른 역할 제안은 실행 실적이 아니다.

지적처리
High — UIScene 생명주기설치된 Flutter 엔진의 연결 옵션 변환에는 userActivities·notificationResponse 전달 공백이 있다. Branch·AppLinks의 콜드 링크 처리와 알림 전달을 종단 검증하지 못했다. 후보를 실행 코드에서 제외했다. 호환성 문제 자체를 해결한 것으로 처리하지 않는다.
Medium — 버튼 접근일반 카드의 바깥 드래그 전달은 수정 후 독립 재검토에서 확인됐다. 재검토가 추가 지적한 달성형은 보상 5개 fixture로 실패를 재현하고 공통 스크롤로 수정했다.
Low — 추가 회귀예정·진행·종료·달성형 각각의 직접 드래그·재시도 탭 테스트를 추가했다. 다음 투표의 제목 잘림을 수정했다. 이 두 후속 수정은 로컬 테스트로 확인했으며 추가 독립 재승인은 수행하지 않았다.
Low — 후속 범위중앙 600 너비 영역의 displayFeatures·좌우 padding 좌표 변환은 기존 동작을 유지한다. 힌지 기준 분할 도입 시 별도 처리가 필요하다. ttja_app 스모크는 --no-pub 실행 시 flutter_test를 찾지 못해 실행하지 못했다.
  • Duo 지원을 완료하려면 UIScene 전달 경로를 수정한 뒤 콜드·웜 Branch 링크, custom scheme, FCM·로컬 알림 탭, 푸시 토큰, Kakao 복귀를 검증해야 한다. 그 후 독립 리뷰를 다시 받아야 한다. Flutter 공식 UIScene 전환 문서를 기준으로 진행한다.
  • Duo iOS 27.1의 실제 키보드 열기·접기·펼치기·닫기는 미해결이다. 해당 실패 검사를 제거하거나 통과로 바꾸지 않았다.
  • 카드 끝에서 관성 스크롤만 남은 경우 바깥 창을 더 보려면 추가 드래그가 필요할 수 있다. 드래그 전달은 손가락이 닿아 있는 OverscrollNotification에만 적용한다.
  • 전역 MediaQuery를 직접 사용하는 배너·게시물·일부 투표 페이지, ScreenUtil의 전체 창 기준 확대와 두 열 구성은 후속 범위다.
  • 실제 One UI Fold8 및 실서비스 광고·오퍼월 복귀는 확인하지 않았다. 이번 작업은 기기 전체 호환성 인증이나 배포 승인 결과가 아니다.

정리

테스트용 iPad·Duo 시뮬레이터와 전용 Android AVD를 종료했다. Android 임시 크기·밀도를 초기화했다. 다른 QA 시뮬레이터와 연결된 실기기는 건드리지 않았다. 리뷰 작업자 터미널과 임시 정책 컨텍스트를 정리했다. 배포·push·merge는 수행하지 않았다.
