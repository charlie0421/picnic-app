고객문의 오류·첨부큰 글씨에서 오류 안내와 재시도 버튼이 최대 95px 넘쳤다. 첨부 미리보기와 입력을 함께 표시하면 최대 101px 넘쳤다.오류 화면과 입력 영역에 스크롤을 제공한다. 재시도·첨부 삭제·전송 버튼의 접근성을 테스트했다. 실제 전송은 하지 않았다.
달성형 투표긴 제목·큰 글씨에서 고정 헤더가 최대 580px 넘쳐 보상 목록에 접근하지 못했다.제목·후보·보상 목록을 같은 페이지에서 스크롤한다. 당겨서 새로고침과 투표 폴링을 유지한다. 숫자 애니메이션의 중첩 스크롤 알림은 페이지 폴링 제어에서 제외한다.
달성 목표 숫자글자 2.6배에서 123,456,789가 고정 50px 높이를 벗어나 잘렸다.실제 글꼴·배율로 목표 숫자 높이를 측정해 단계 높이를 늘린다. 진행 막대에도 같은 단계 높이를 적용한다. 숫자는 생략하거나 축소하지 않는다. 큰 글씨의 긴 숫자는 여러 줄로 표시한다.
제휴 투표 입력키보드가 표시된 상태의 창 크기 전환.위젯 검증 18개에서 입력값과 커서가 유지됐다. 화면 코드의 추가 수정은 없었다.

검증 범위의 한계

  • Duo는 iOS 27.1 Simulator를 사용한다. Galaxy Fold8은 Android API 35 에뮬레이터에서 커버 400×640과 펼침 800×600 비율을 재현한다. 실제 Fold8 하드웨어·One UI 결과로 해석하지 않는다.
  • 사용자 확인: Duo 실기기는 확보할 수 없다. 현재 확보 가능한 검증 범위는 시뮬레이터·자동화 테스트이며, Duo 실기기 호환성을 확인했다고 표시하지 않는다. Duo 실기기 확보를 이번 작업의 필수 대기 조건으로 두지 않는다.
  • 사용자 확인: 내부 테스터가 Galaxy Fold8 실기기를 보유한다. 실기기 결과는 아직 받지 않았다. 아래 절차로 One UI·키보드·접기 전환을 확인한다. 앞선 자동화 실행 당시 연결된 SM-G781N(Android 13)은 변경하지 않았다.
  • 첨부 검증은 선택된 파일의 미리보기·삭제 UI를 포함한다. OS 사진 선택기의 권한 전환, 실제 파일 업로드, 영상 재생·전체 화면 이미지 탐색의 폴드 전환은 이번 검증에 포함하지 않았다.
  • 실제 문의·투표·결제·광고 기능의 서버 통합은 별도 검증이 필요하다.

시작 전 기록

  • 기기 모델명, Android·One UI 버전, 앱 버전·빌드번호, 설치 경로를 기록한다.
  • 앱 빌드에 PR #303의 UI 수정이 포함됐는지 빌드 소스 커밋과 PR의 최종 병합 커밋으로 확인한다. 버전·빌드번호만으로 포함 여부를 추정하지 않는다. 기존 기록의 510bdfb14는 rebase 전 검증 커밋이다. 기존 자동화용 테스트 앱이 아닌 일반 앱 진입점으로 빌드한 Picnic 앱을 사용한다.
  • 키보드 종류, 글자 크기, 화면 확대 설정, 접은 뒤 커버 화면에서 앱을 이어 쓰는 설정 상태를 기록한다.
  • 답변이 있는 테스트용 고객문의와 달성형·제휴 투표 데이터를 준비한다. 필요한 데이터가 없으면 해당 항목은 미실행으로 기록한다.

일반 글자 크기로 확인한 뒤 큰 글자·화면 확대 조건에서도 확인한다. OS 설정 단계와 앱의 글자 배율 2.6을 같은 값으로 간주하지 않는다. 각 항목은 통과·실패·미실행 중 하나로 기록한다. 이 절차는 UI 점검이며 실제 문의 전송·투표 확정·결제는 포함하지 않는다.

항목테스터 행동기대 결과
1. 주요 화면홈·투표·충전·마이페이지를 접힌 화면과 펼친 화면에서 연다.기존 한 열 구성이 유지된다. 본문·버튼·하단 메뉴가 겹치거나 화면 밖으로 밀리지 않는다.
2. 고객문의 입력고객문의 답변 입력란에 초안을 입력한다. 커서를 문장 중간에 둔다. 키보드를 띄운 상태로 펼친다. 다시 접는다.앱을 이어 쓰는 설정에서 초안과 커서가 유지된다. 입력란과 전송 버튼에 접근할 수 있다. 긴 안내문은 스크롤해서 읽을 수 있다. 화면이 꺼지는 OS 동작은 앱 레이아웃 오류와 구분해 기록한다.
3. 문의 첨부·종료테스트 이미지 선택 화면을 연다. 이미지를 선택하거나 선택을 취소한다. 선택한 첨부를 삭제한다. 종료된 문의를 연다.선택·취소 후 앱 화면으로 돌아온다. 미리보기와 삭제 버튼에 접근할 수 있다. 종료 안내를 읽을 수 있고 입력은 차단된다. 파일은 전송하지 않는다.
4. 문의 로딩 오류테스트용 데이터에서 로딩 실패를 재현할 수 있으면 오류 화면을 연다. 초안을 입력한다. 연결 복구 후 재시도를 누른다.오류 안내와 재시도 버튼에 접근할 수 있다. 재시도 후 초안이 유지된다. 재현하지 못하면 통과 대신 미실행으로 기록한다.
5. 달성형 투표제목이 긴 달성형 투표를 연다. 목표 숫자와 보상 목록까지 스크롤한다. 접기·펼치기 후 화면을 확인한다.제목 때문에 목록에 접근하지 못하는 현상이 없다. 목표 숫자의 모든 자릿수를 읽을 수 있다. 큰 글씨에서 줄바꿈은 허용하지만 잘림·겹침은 없어야 한다. 진행 막대와 단계 표시가 어긋나지 않는다.
6. 제휴 투표 입력제휴 투표 입력창을 연다. 수량을 입력한 뒤 커서를 중간에 둔다. 키보드가 열린 상태로 접고 펼친다. 확정하지 않고 닫는다.입력 수량과 커서가 유지된다. 키보드가 입력란·닫기 동작을 가리지 않는다.
7. 회전·분할 화면고객문의와 투표 화면에서 지원되는 가로 화면 또는 분할 화면으로 전환한다. 원래 크기로 복귀한다.짧은 화면에서도 필요한 내용과 버튼에 스크롤로 접근할 수 있다. 복귀 후 화면이 비거나 겹치지 않는다. 지원하지 않는 모드는 미실행으로 기록한다.
8. 앱 복귀초안 입력 중 홈 화면으로 이동한다. 기기를 접거나 펼친다. 최근 앱에서 Picnic으로 복귀한다.앱 프로세스가 유지된 상태에서 화면과 초안이 유지된다. 새로 시작한 경우에는 종료·재실행 여부를 따로 기록한다.
