# 마이페이지 관리자 메뉴 모음 설계

## 목표

마이페이지에 흩어져 있는 관리자 전용 기능을 `관리자` 진입점 하나로 모으고, 일반 사용자 메뉴와 운영·테스트 기능을 명확히 분리한다.

## 메뉴 구조

- 로그인한 관리자에게만 마이페이지에 `관리자` 메뉴를 노출한다.
- `관리자`를 선택하면 별도의 관리자 메뉴 화면으로 이동한다.
- 관리자 화면에는 다음 항목을 기존 순서와 동작으로 제공한다.
  - 캔디 내역: 기존 `CurrencyHistoryPage`로 이동
  - 충전 내역: 현재 구현된 빈 동작을 유지한다
  - Ad Inspector: 기존 Google Mobile Ads Inspector 실행
  - Reset & Reload GDPR: 기존 동의 초기화 및 재초기화 실행
- 마이페이지에 직접 노출되던 위 네 항목과 관리자 구분선은 제거한다.
- 알림함은 관리자 메뉴에 포함하지 않고 로그인 사용자 공통 메뉴로 유지한다.

## 권한 처리

- 일반 사용자와 로그아웃 사용자에게는 마이페이지의 `관리자` 진입점을 표시하지 않는다.
- 관리자 메뉴 화면은 렌더링 시점에도 `userInfoProvider`의 `isAdmin`을 확인한다.
- 관리자 권한이 없으면 관리자 항목을 렌더링하지 않고 본문 중앙에 `접근 권한이 없습니다.`를 표시한다. 기존 하위 화면의 상단 뒤로가기로 마이페이지에 복귀한다.
- 관리자 하위 기능의 기존 서비스 호출 및 오류 메시지는 변경하지 않는다.

## 화면 구성

- 기존 마이페이지 하위 화면 패턴과 동일한 상단 타이틀 및 뒤로가기 동작을 사용한다.
- 화면 타이틀과 진입점 라벨은 `관리자`로 표시한다.
- 항목은 기존 `PicnicListItem`을 재사용해 마이페이지와 시각적 일관성을 유지한다.
- 새로운 아이콘이나 네트워크 요청은 추가하지 않는다.

## 검증

- 관리자 마이페이지에는 `관리자`만 보이고 개별 관리자 항목은 보이지 않아야 한다.
- 일반 사용자와 로그아웃 사용자에게는 `관리자`가 보이지 않아야 한다.
- 관리자 화면에는 네 항목이 모두 보여야 한다.
- 비관리자가 관리자 화면을 직접 렌더링하면 관리자 항목이 노출되지 않아야 한다.
- 캔디 내역 이동, Ad Inspector, GDPR 동작은 기존 동작을 유지해야 한다.
- 대상 위젯 테스트와 Flutter 정적 분석을 통과해야 한다.
