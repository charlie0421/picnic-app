# PICNIC-2232 소멸 안내 전체 화면 다이얼로그 설계

## 목표

소멸 예정 캔디 안내를 라운드 카드형 팝업에서 앱의 기존 리워드 팝업과 동일한 전체 화면 다이얼로그로 변경한다.

## 범위

- `showUsagePolicyDialog`는 `showFullScreenDialog`를 사용한다.
- `UsagePolicyPopup`은 `LargePopupWidget` 대신 `FullScreenDialog`를 사용한다.
- 배경은 흰색 전체 화면으로 표시한다.
- 우측 상단에는 기존 `FullScreenDialog`의 원형 닫기 버튼을 표시한다.
- 제목과 본문은 SafeArea 안에 배치한다.
- 본문 전체를 세로로 스크롤할 수 있게 한다.
- 기존 코튼캔디, 보너스 스타캔디, 소멸 시점, 예시, 정책 콘텐츠와 로컬라이제이션은 유지한다.
- 로그인 여부와 보너스 조회의 성공·로딩·실패 상태 동작은 유지한다.
- 기존 확대/축소 전환과 `LargePopupWidget`의 라운드 셸, 0.82 화면 높이 제한을 제거한다.

## 비범위

- 관리자 메뉴 구성과 접근 제어는 변경하지 않는다.
- 지갑 API, 소멸 계산, 결제 및 투표 이력 데이터 흐름은 변경하지 않는다.
- 신규 이미지 에셋을 추가하지 않는다.

## 테스트

- 호출 시 `FullScreenDialog`가 열리고 닫기 버튼으로 닫히는지 검증한다.
- `LargePopupWidget`이 더 이상 렌더링되지 않는지 검증한다.
- 작은 화면과 확대 텍스트에서도 본문이 스크롤되며 레이아웃 오버플로가 없는지 검증한다.
- 로그인, 비로그인, 조회 실패 상태의 기존 콘텐츠가 유지되는지 검증한다.
- 기존 라운드 팝업 골든을 전체 화면 레이아웃 골든으로 갱신한다.
