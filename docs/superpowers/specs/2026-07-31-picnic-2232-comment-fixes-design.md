# PICNIC-2232 댓글 반영 설계

## 목적

Jira PICNIC-2232 본문 구현 이후 등록된 댓글 5건을 기존 상점·무료충전소·마이페이지 구조 안에서 최소 범위로 반영한다. 결제, 지갑 데이터, 투표 이력 조회 로직은 변경하지 않는다.

## 결정 사항

### 아이콘 일관성

- 상점의 개별 별사탕 구매 항목은 수량별 장식 이미지 대신 앱에서 사용하는 표준 스타캔디 통화 아이콘을 사용한다.
- 마이페이지의 별사탕 투표 이력 항목도 같은 표준 스타캔디 아이콘을 사용한다.
- 소멸 예정 캔디 안내의 보너스 스타캔디 소멸 시점 제목에는 기존 보너스 스타캔디 통화 아이콘을 함께 표시한다.
- 새로운 이미지 에셋은 추가하지 않고 기존 `currency_star_candy.png`와 `currency_bonus_star_candy.png`를 재사용한다.

### 무료충전소 문구

- 미션 섹션 제목을 “미션에서 보너스 스타캔디 받기” 의미로 변경한다.
- 미션 보상 문구를 “+보너스 스타캔디 … 획득” 형식으로 변경한다.
- 광고 섹션은 코튼캔디 보상임을 드러내고, 보상 문구를 “+코튼캔디 … 획득” 형식으로 변경한다.
- 기존 다국어 키를 의미가 달라진 값으로 덮어쓰기보다는 보상 종류가 명확한 전용 키를 사용한다. 지원 로케일의 ARB와 생성 로컬라이제이션을 함께 갱신한다.

### 소멸 예정 안내

- 현재 보너스 스타캔디 구역의 “소멸 시점 안내” 제목을 아이콘과 “보너스 스타캔디 소멸 시점 안내” 문구가 결합된 헤더로 바꾼다.
- 기존 날짜 계산, 펼침/접힘, 스크롤, 코튼캔디/정책 구역 구조는 유지한다.

### 마이페이지 캔디 파우치와 내역

- 마이페이지에서도 구매 탭과 무료충전소가 공유하는 `StorePointInfo` 캔디 파우치 모듈을 그대로 사용한다.
- 로그인한 일반 사용자와 관리자 모두 공통 모듈에서 캔디 파우치를 볼 수 있다.
- 로그아웃 사용자에게도 공통 모듈을 노출하고, 모듈에 이미 구현된 로그인 유도 UI와 동작을 유지한다.
- 캔디 내역 메뉴는 관리자 계정에만 노출한다.
- 비관리자가 다른 경로로 캔디 내역 페이지에 진입해도 내용을 조회할 수 없도록 접근을 차단한다.
- 캔디 내역 페이지 자체는 관리자 운영·테스트 용도로 유지한다.

## 테스트

- 각 댓글 요구사항을 식별할 수 있는 위젯 테스트를 먼저 추가하거나 기존 테스트의 기대값을 변경한다.
- 마이페이지 테스트는 일반 사용자에게 공통 캔디 파우치가 보이고 캔디 내역 메뉴는 보이지 않는지, 관리자에게는 둘 다 보이는지 검증한다.
- 로그아웃 사용자에게 공통 모듈의 로그인 유도 UI가 보이고 캔디 내역 메뉴는 보이지 않는지 검증한다.
- 캔디 내역 페이지 테스트는 비관리자의 직접 진입이 차단되는지 검증한다.
- 상점 구매 항목, 무료충전소, 소멸 예정 안내, 마이페이지, 투표 이력의 관련 테스트를 실행한다.
- 소멸 안내 레이아웃이 바뀌므로 레이아웃·골든 테스트를 확인하고, 의도된 차이만 골든에 반영한다.
- 마지막으로 변경 파일 대상 정적 분석과 전체 관련 테스트를 실행한다.

## 비범위

- 결제 처리, 상품 가격, 지갑/만료 API, 투표 이력 데이터 조회 변경
- 신규 에셋 제작
- Jira 상태·댓글 수정
- 커밋, 푸시, PR 생성
