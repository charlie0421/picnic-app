# 별사탕 파우치 간격 정리 설계

## 목표

구매 탭, 무료 충전소, 마이페이지에서 공통 `StorePointInfo`를 사용할 때 화면별로 달라 보이는 외부 간격을 일관된 규칙으로 정리한다. 파우치 내부 디자인과 정보 구조는 변경하지 않는다.

## 적용 위치

- 별사탕 구매 탭의 파우치
- 무료 충전소의 파우치
- 마이페이지의 파우치

## 간격 규칙

- `StorePointInfo`의 기본 상단 마진은 제거한다. 공통 컴포넌트는 자신의 외부 배치를 결정하지 않는다.
- 각 화면은 파우치 앞뒤 간격을 명시적으로 배치한다.
- 구매 탭: 화면 상단에서 파우치까지 16, 파우치에서 다음 구분 영역까지 16.
- 무료 충전소: 화면 상단에서 파우치까지 16, 파우치에서 미션 섹션까지 16.
- 마이페이지: 프로필 영역에서 파우치까지 16, 파우치에서 언어 설정 섹션까지 24.
- 로그아웃 상태에서도 마이페이지의 파우치 배치 규칙은 동일하다.

## 구현 범위

- 공통 파우치의 `topMargin` 기본값을 `0`으로 변경한다.
- 세 소비 화면에 `SizedBox`를 사용해 승인된 외부 간격을 명시한다.
- 기존 Divider의 시각적 역할은 유지하되, 파우치와 Divider 사이의 중복 여백은 제거한다.
- 파우치 높이, 테두리, 라운드, 내부 패딩, 재화 표시 및 새로고침 동작은 변경하지 않는다.

## 검증

- 위젯 테스트에서 세 화면의 파우치 앞뒤 간격을 숫자로 검증한다.
- 로그인/로그아웃에 따른 파우치 노출 정책과 기존 기능 테스트가 계속 통과해야 한다.
- 변경 파일에 대해 Flutter 정적 분석을 실행한다.
