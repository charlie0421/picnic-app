# PICNIC-2232 소멸 안내 및 관리자 메뉴 설계

## 목표

1. 소멸 예정 캔디 안내를 기존 카드형 팝업에서 리워드 팝업과 같은 전체 화면 다이얼로그로 변경한다.
2. 캔디 내역을 관리자만 볼 수 있게 하고, 관리자 전용 기능을 `관리자 메뉴` 섹션으로 명확히 구분한다.

## 소멸 예정 캔디 안내

- `showFullScreenDialog`와 `FullScreenDialog`를 사용한다.
- 화면은 흰색 전체 화면이며 우측 상단에 리워드 팝업과 동일한 원형 닫기 버튼을 둔다.
- 제목과 정책 콘텐츠는 안전 영역 안에 배치하고, 본문 전체를 세로 스크롤할 수 있게 한다.
- 현재 제공하는 코튼캔디, 보너스 스타캔디, 소멸 시점, 예시, 이용 정책 정보와 다국어 문구는 유지한다.
- 로그인 여부와 조회 성공·로딩·실패 상태의 기존 동작도 유지한다.
- 기존 `LargePopupWidget` 셸과 확대/축소 전환 효과는 제거하고 전체 화면 다이얼로그 전환을 사용한다.

## 관리자 메뉴

- `userInfo.isAdmin == true`인 경우에만 `관리자 메뉴` 섹션을 표시한다.
- 관리자 전용 항목을 이 섹션에 모은다.
  - 캔디 내역
  - 충전 내역 (관리자)
  - Ad Inspector
  - Reset & Reload GDPR
- 알림함은 개인별 투표·게시글·QnA 알림을 보여주는 일반 사용자 기능이므로 기존 일반 메뉴 영역에 둔다. 마이페이지에서도 관리자 조건을 제거해 상단 알림 아이콘과 접근 정책을 일치시킨다.
- 상단 캔디 잔액은 메뉴가 아니므로 기존 위치를 유지하되 관리자에게만 표시한다.
- 일반 사용자, 비로그인 사용자, 프로필 로딩 실패 상태에는 관리자 메뉴 전체를 표시하지 않는다.
- 기존 다국어 `충전 내역 (관리자)` 문구는 유지한다.
- `관리자 메뉴` 제목은 새 다국어 키로 제공한다.

## 접근 제어

- 메뉴 노출 조건과 별도로 `CurrencyHistoryPage` 진입 시 관리자 여부를 다시 확인한다.
- 일반 사용자, 비로그인 사용자, 권한 확인 전 상태에서 직접 라우트나 딥링크로 접근하면 콘텐츠를 렌더링하지 않고 내 페이지로 복귀시킨다.
- 접근 제어는 앱 UI 계층의 방어이며, 서버 데이터 권한은 기존 RLS 정책을 그대로 따른다.

## 테스트

- 소멸 안내가 `FullScreenDialog`로 열리고 닫히는지 검증한다.
- 작은 화면에서도 본문을 끝까지 스크롤할 수 있는지 검증한다.
- 관리자에게만 `관리자 메뉴`와 캔디 내역이 표시되는지 검증한다.
- 비관리자가 직접 캔디 내역 화면에 접근해도 콘텐츠가 표시되지 않는지 검증한다.
- 기존 사용 정책 위젯 테스트와 골든 이미지를 새 전체 화면 레이아웃에 맞게 갱신한다.
- 자동 테스트 후 실제 Android 장비에서 수정 화면을 확인하고 캡처한다.
