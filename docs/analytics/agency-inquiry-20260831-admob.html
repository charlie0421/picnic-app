선택지의미
A. 포함권고 AdMob 지면도 분석 대상. 자동 수집 이벤트를 그대로 활용하고, 모든 광고 리포트를 ad_platform으로 분리해서 봅니다. 저희가 추가로 보낼 것은 없습니다.
B. 제외 자체 숏폼·Pangle만 계측 대상. AdMob 자동 이벤트는 리포트에서 제외합니다. 스펙은 그대로 두고 분석 시 ad_platform으로 걸러냅니다.

A를 권합니다. AdMob이 실제 수익 지면이고 데이터가 이미 무료로 들어오고 있어, 빼면 광고 성과의 상당 부분이 리포트에서 사라집니다. 저희 쪽 추가 개발도 필요 없습니다.

다만 A로 가면 규칙이 하나 필요합니다 — 광고 이벤트는 항상 ad_platform으로 나눠 봐야 합니다. 합산하면 자체 숏폼 CTA와 AdMob 클릭이, 자체 노출과 AdMob 노출이 뒤섞입니다.

회신 요청

A(포함) 또는 B(제외) 중 선택해 주세요. A를 택하시면 ad_reward를 스펙에 추가할지, 그리고 AdMob ad_click과 저희 ad_cta_click을 리포트에서 어떻게 구분해 표기할지도 함께 정해주시면 반영하겠습니다.
