ad_click 이벤트명을 바꿔야 합니다

ad_click은 Google이 앱에서 쓰지 못하게 막아둔 예약 이벤트명입니다. 구현은 정상이지만 Firebase SDK가 전송 자체를 거부해 28일간 0건입니다. 같은 화면·같은 코드에서 발생하는 ad_impression은 같은 기간 102,405건 정상 수집됩니다. 예약어가 아니기 때문입니다.

실기기에서 CTA 버튼을 눌러 광고주 랜딩으로 이동하는 과정을 로그로 확인했습니다. 파라미터까지 전부 채워진 뒤 마지막 전송 단계에서 이름만 거부됩니다.

[internal] more pressed
Invalid argument (name): Event name is reserved and cannot be used: "ad_click"
  at _logEventNameValidation (firebase_analytics.dart:1346)

앱에서 다른 이름으로 보내고 GA4에서 ad_click으로 되돌리는 우회도 검토했으나, GA4 이벤트 수정 문서가 “새 이름이 예약어가 아닌지 확인하라”고 명시하고 있어 불가능합니다. 이름을 바꾸는 것 외에 방법이 없습니다.

어느 이름으로 바꿀지 정해 주세요

  • ad_cta_click — 실제 동작에 가장 가깝고 다른 광고 지면에도 확장 가능 (권고)
  • shortform_ad_click — 자체 숏폼 한정임이 이름에 드러남
  • select_promotion — GA4 표준 추천. 표준 리포트에 얹히나 의미가 정확히 맞지는 않음

어느 안이든 트리거 시점(전체화면 CTA 클릭)과 파라미터는 현행 그대로이며, 앱은 이벤트명만 교체해 배포합니다.

이름이 확정되어야 배포가 가능하고, 배포 전까지 계속 0건입니다. 소급 수집은 되지 않아 확정 이후 데이터만 쌓입니다.
